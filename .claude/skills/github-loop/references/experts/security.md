# Expert: security

Selected for every high-risk change: authentication, permissions, secrets, sensitive data, deploys, workflows, or the loop's own skill.

- No secret, token, PIN, password, sheet or script ID, e-mail address or real staff name in the diff, the tests or a comment.
- Access is never made wider than the plan says. A new role, a changed permission or a wider sharing setting is a stop-and-ask item.
- Every server entry point checks who is calling before doing anything.
- Errors do not reveal whether an account exists or why access failed.
- Inputs that reach a query, a formula or HTML are escaped or parameterized.
- The owner merges high-risk work (merge exits 8): say so in the plan's merge plan.
- Review at opus when it can run (route.py says the tier), the full checklist on every changed line, every round.
