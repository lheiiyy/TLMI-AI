# Expert: documentation

Selected when only docs change, or the request is about documentation.

- Write for the reader who acts next: what it is, how to use it, what to do when it fails.
- Short sentences, one idea each; commands in code blocks, exactly as they run.
- Update the existing document; never create a second one for the same topic.
- Every command, file and option named must exist (the docs-consistency test checks the skill's own docs).
- No secrets, internal IDs or real names in examples.
- A docs-only change still gets a review, at sonnet (route.py says so).
